# يومي

منصة لتنظيم الوقت، تعمل على الجوال والحاسوب، وبدون إنترنت بعد أول فتح.

- **خطّط (صباحًا):** أفرغ ذهنك، ميّز المهم من العاجل، اختر أهم ٣، ثم حدّد الوقت.
- **يومي:** جدولك حسب الوقت، مع التقسيمات (الدراسة، العبادات…) ومجموع ساعات كل تقسيم.
- **راجع (التقرير):** هل أنت متقدّم أم متراجع اليوم مقارنة بمعدّل الأيام الثلاثة السابقة، لكل تقسيم وللمجموع.
- **المهام الدائمة:** تنزل تلقائيًا في الأيام التي تختارها لكل مهمة.
- التاريخ الهجري مع الميلادي.

## البيانات
- تُحفظ على الجهاز أولًا، فتعمل بدون إنترنت.
- مع Supabase: صف واحد لكل مستخدم يُفتح بكود، فيه سبعة حقول (اليوم الحالي و٣ أيام قبله و٣ بعده).
- الربط بين الأجهزة بالكود، أو برمز QR مثل واتساب.

خطوات تفعيل Supabase في [SUPABASE_SETUP.md](SUPABASE_SETUP.md).
